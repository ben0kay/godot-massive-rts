# Game ideas

Use this folder to save ideas worth revisiting after a design discussion. Add an idea here when the owner asks to keep it. An entry records a proposal. Implementation starts when the owner requests it.

| Category | What belongs there |
| --- | --- |
| [Gameplay mechanics](gameplay-mechanics.md) | Combat rules, movement, terrain interactions, and new ways to play |
| [Units and defenses](units-and-defenses.md) | New units, towers, aircraft, and changes to their roles or balance |
| [Visual updates](visual-updates.md) | Models, animations, lighting, terrain art, and battle effects |
| [UI and controls](ui-and-controls.md) | HUD, menus, deployment controls, editor tools, and accessibility |
| [Maps and modes](maps-and-modes.md) | Skirmish scenarios, Fortress Defense waves, campaign, and progression |
| [Audio](audio.md) | Weapon sounds, alerts, ambience, and music |

## Adding an idea

Pick the file that best fits the idea's main purpose. Link to that entry from another category if it spans both. Keep related refinements together and preserve any constraints the owner mentioned.

```markdown
## Idea title

- **Proposal** — What would change and how the player would experience it.
- **Goal** — What would improve, or what problem this would solve.
- **Notes** — Optional tuning, performance constraints, related features, or open questions.
```

Prompt for another chat:

> Add this idea to the appropriate file in `IDEAS/` using the format in `IDEAS/README.md`. Keep the details we agreed on and record any open questions. Update the docs only.
