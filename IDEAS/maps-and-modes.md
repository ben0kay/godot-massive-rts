# Maps and modes

Skirmish scenarios, Fortress Defense waves, campaign, and progression.

## Procedural terrain / map generator

- **Proposal** — Add a seeded Generate Terrain tool to the existing Level Editor: adjustable map size, biome, elevation, forest/rock density, rivers, bridge placement and protected deployment/build zones. Generate fully editable battlefield data, not a separate runtime map format.
- **Goal** — Rapidly produce varied, playable battlefields for Missions, Skirmishes, Fortress Defense and eventually strategic Campaign territory encounters.
- **Notes** — See the dedicated [Procedural Map Generator — Codex proposal](procedural-map-generator.md) for UX, staged implementation, deterministic persistence, integration, performance and acceptance checks. This is an idea, not implementation authorization.
