# Fortress Defense waves

Command levels expose `WaveDefinitions`, `BetweenWavesSeconds`, `EnemySpawnEdge`, and `EnemySpawnRate` on the scene root. Each `WaveDefinition.cs` resource maps stable soldier IDs to counts. `FortressWaves.cs` releases troops just inside the selected boundary and leads them toward the Citadel. South (+Z) is the default. Lanes spread along the edge near the Citadel's coordinate. Leave open space at the entry so the wave can release.

Enable **Wave Editor** in **Project Settings → Plugins** after building the C# project. Open the Command Sandbox or an inherited level and click **Wave Editor** in the bottom panel. Edit the edge, time between waves, spawn rate, and counts, or add and remove waves. Save the open scene to keep its settings. The Inspector remains another way to edit the same data.

A centered Citadel is roughly 2,500 world units from an edge. On the current sandbox that means several minutes of travel before contact. EnemySpawn markers from older scenes are obsolete.

`FortressWaves` advances the wave state, uses the shared spatial grid for local soldier detection, issues movement through `CommandMovement`, and reuses soldier combat and projectile flight. Citadel-targeted shots resolve against the building and can be blocked by cover. They do not retarget to soldiers in flight. Legacy wave units attack soldiers and fall back to their scripted Citadel assault. Units configured to target structures instead use the shared footprint-based acquisition and attack logic, including attacks on player Fabricators. The sandbox includes a red practice Fabricator for blue structure-capable units. Enemy IDs are reserved up front so fabricating units cannot exhaust wave capacity.

### Spawn patterns

**Stream** uses the first free lane starting at the middle. **Scatter** picks a seeded random lane for each arrival and uses Lane spacing to spread entries along one map edge. Both use the scene-wide **Spawn rate (units/s)** setting in the Wave Editor (also `EnemySpawnRate` on the command level root). Default **6.25 units/s = 0.16 seconds per soldier** preserves the previous release cadence; increase to spawn more frequently, up to 60 units/s (one attempt per 60 Hz physics step). A blocked spawn is retried without consuming its unit, and the scheduler retains fractional tick time rather than rounding every interval up to a whole tick. Actual releases may be slower when lanes are blocked. **Rows** releases a row together, then waits for its existing **Row delay**; Spawn rate does not affect Rows. Set Units per row and Lane spacing in the Wave Editor or level root Inspector. After spawning, troops advance independently toward the Citadel. Fortress Defense Level 001 uses Scatter. The rate is a command-level setting shared by its waves, not a per-wave override.
